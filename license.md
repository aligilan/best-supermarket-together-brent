## 🧱 When The Game Updates And The Tool Does Not

The most common real-world failure, and what it looks like from the inside.

**The sequence**

A game patch changes memory layout. The tool's offsets no longer point at the
right data. Modules either do nothing, or read nonsense and misbehave.

**Symptoms ranked by how they present**

| **Symptom** | **Likelihood it is a patch** |
| --- | --- |
| Everything worked yesterday | very high |
| Overlay draws, values wrong | very high |
| Menu will not open | low — that is an attach problem |
| One module broken, others fine | low — that is that module |

**What to do**

Check for a tool update first. If none exists, the honest answer is that the
build predates the patch and you wait. There is no configuration change that
fixes stale offsets.

**What not to do**

Do not start changing values to compensate. If the data being read is wrong,
tuning it produces wrong results faster, and you lose the known-good config in
the process.

**The recovery**

When an update lands, load your saved preset rather than re-tuning. That is the
entire reason presets exist.
